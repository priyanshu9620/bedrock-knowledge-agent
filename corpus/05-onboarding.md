# Onboarding

- Day 1: laptop, accounts and a welcome session. An onboarding buddy is assigned for the first 90 days.
- Every new joiner has a 30/60/90-day plan agreed with the manager in the first week.
- Probation lasts 6 months. A probation review is held in month 3 and month 6.
- Mandatory trainings (security awareness, code of conduct, POSH) must be completed within 14 days of joining.
- The employee ID format is E followed by four digits, for example E1001.
