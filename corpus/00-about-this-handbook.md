# Meridian Labs Employee Handbook — About

Meridian Labs is a fictional software company used for this demo. This handbook is the single source of truth for
people policies. Where a policy and a manager's instruction differ, the policy wins. Policies are reviewed every
January. Questions go to people-ops@meridianlabs.example. The handbook has these sections: leave, expenses, travel,
IT security, onboarding, devices, remote work, holidays, benefits, code of conduct, incident process, glossary.
